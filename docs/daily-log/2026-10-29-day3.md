## UI-06A R1 — Focused-state pixel difference investigation (29 Oct 2026)

**Status:** ready for review. **Day 3 remains OPEN.**

**Scope:** diagnostic only, on branch `day3/ui-06a-r1-focus-parity` from `4c501c4`. No product, CSS or semantics change; parity harness untouched.

**Why:** the architect asked for the ~500 px outside-ring differences in focused draft-editor states to be identified, not assumed harmless.

**AI involvement:** Claude Code designed and ran the localisation, the experiments and the control. Architect and owner review are pending.

**Method:** zero-threshold diff masks were checked against each focused element's outline region (rect + offset + width + 1 px). Outside pixels were clustered and cropped. Each capture was repeated 3 times, then rerun with the caret hidden in both pages and with the reference plus the UI-06A CSS.

**Results:**
- 24/24 cases are deterministic.
- Primary-select cases: 0 outside pixels.
- Draft-editor cases: 238–904 outside pixels, at most 1–4/255 per channel, on button corners and glyph edges. Hiding the caret changed nothing.
- **Reference + UI-06A CSS: 0 px in all 24.**
- All cases classified `EXPLAINED_ACCESSIBILITY_EXCEPTION`.
- The earlier ~504 px estimate is corrected to 238 for `review-empty-draft-1440`.

**Problems encountered:** the first evidence run cropped every 6 px cluster (780 images). Crops are now grouped into 24 px regions, giving 381 images that still cover every outside pixel.

**Verification:** `ui06a-r1-diff-localization.spec.ts` 72/72; see the final report for the remaining gates.

**Paid calls: 0.** Unlearning: none added.
