## Security notes and limitations
- `/api/process` is local only: loopback `Host`, same-origin `Origin`, JSON only, a 64 KB body cap and strict Zod validation, and at most 10 messages, all checked before any call. It has no authentication or rate limiting, so it must not be deployed publicly. The `Host` header can be spoofed, so these checks are not a security boundary.
- The model, prompt and parameters are fixed on the server. The key is read only on the server (`server-only` guard) and was not found in `.next/static`.
- Candidate text is sent as JSON with `<` escaped, inside a delimiter marking it as untrusted.
- Outputs are re-validated: strict schema, bounded lengths, no markup, valid intents only.
- The deterministic phrase check blocks hire claims whatever the model reports. It is a limited list and does not prove a draft safe.
- The CSV keeps its 14 accepted columns and has no provenance column; the UI shows provenance. A provenance column would need a contract change.
- Formal WCAG 2.2 AA certification remains UI-06 work.
